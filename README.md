# To-Do List Web App

A front-end To-Do List application built with HTML, CSS, and vanilla JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- Save tasks using localStorage
- Responsive design
- No page reload required for updates

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` with Live Server.
4. Use the input field to add tasks.

## Project Files

- `index.html` contains the page structure.
- `style.css` contains the styling.
- `script.js` contains the application logic.
